Wildlife Quiz

An interactive wildlife trivia quiz built using HTML, CSS and JavaScript.

Features

1)Multiple-choice questions

2)Instant answer validation

3)Live score tracking

4)Animated question transitions

5)Final score and retry option

made using : HTML, CSS, JavaScript

How to Play
1. Open the Wildlife Quiz in your browser.
2. Read the displayed question.
3. Select one answer from the multiple-choice options.
4. Click Check Answer to submit your response.
5. View the feedback indicating whether your answer was correct or incorrect.
6. Continue through the remaining questions.
7. View your final score at the end of the quiz.
8. Select Have another go! to restart the quiz.

How to Run

Clone the repository.

Open the project in VS Code.

Launch index.html using Live Server.
